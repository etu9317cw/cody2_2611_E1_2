# 나만의 퀴즈 게임 (E1_2)

터미널에서 동작하는 Python 퀴즈 게임입니다. 메뉴에서 번호를 골라 퀴즈를 풀고, 새 퀴즈를 추가하고, 최고 점수를 확인할 수 있으며, 프로그램을 껐다 켜도 퀴즈와 최고 점수가 `state.json`에 남습니다.

## 1. 프로젝트 개요

- 외부 라이브러리 없이 Python 표준 라이브러리만 사용합니다. (Python 3.10 이상, 개발은 3.12)
- 클래스 2개로 나눴습니다.
  - `Quiz`: 문제 1개(문제 글, 선택지 4개, 정답 번호 1~4)와 출력·정답 확인.
  - `QuizGame`: 퀴즈 목록과 최고 점수를 들고, 메뉴·풀기·추가·목록·점수·저장/불러오기를 맡습니다.
- 잘못된 입력(앞뒤 공백, 숫자가 아닌 글자, 범위 밖 숫자, 빈 입력)은 안내하고 다시 묻습니다. Ctrl+C나 입력 끝(EOF)이 들어오면 저장하고 안전하게 끝납니다.
- 보너스: 랜덤 출제, 풀 문제 수 선택.

## 2. 퀴즈 주제와 선정 이유

**주제: 이번 달 과제 내용 — Git · Python · Docker.**

이 게임을 만드는 달에 실제로 배우는 것들이라, 만들면서 한 번, 퀴즈로 다시 한 번 복습할 수 있다고 생각했습니다. 기본 퀴즈 8개는 `git commit/clone/merge`, 터미널 `pwd`, Python `dict`와 `__init__`, Docker 컨테이너와 `-p` 포트 연결을 다룹니다.

## 3. 실행 방법

```bash
git clone <이 저장소 주소>
cd <저장소 폴더>
python main.py
```

- Windows에서 한글·이모지가 깨지면 VS Code 터미널이나 Windows Terminal에서 실행하세요. (프로그램이 시작할 때 표준 입출력을 UTF-8로 맞춥니다.)
- 메뉴 번호를 입력하고 Enter를 누릅니다. `5`를 누르면 저장하고 종료합니다.

## 4. 기능 목록

| 메뉴 | 기능 |
|---|---|
| 1. 퀴즈 풀기 | 풀 문제 수를 고르면(보너스) 그만큼 **랜덤 순서**(보너스)로 출제합니다. 정답/오답을 바로 알려 주고, 끝나면 점수(100점 만점)를 보여 주며, 최고 점수를 넘으면 갱신·저장합니다. 퀴즈가 없으면 안내합니다. |
| 2. 퀴즈 추가 | 문제, 선택지 4개, 정답 번호를 입력받아 검증한 뒤 추가하고 바로 저장합니다. |
| 3. 퀴즈 목록 | 등록된 퀴즈의 번호와 문제를 보여 줍니다. 없으면 안내합니다. |
| 4. 점수 확인 | 최고 점수와 그때의 정답 수를 보여 줍니다. 아직 풀지 않았으면 안내합니다. |
| 5. 종료 | 저장하고 끝냅니다. |

실행 화면(퀴즈 풀기·추가·목록·점수)은 [`docs/captures.md`](docs/captures.md)에 있습니다.

## 5. 파일 구조

```text
.
├── main.py        # 진입점: 콘솔 UTF-8 설정, QuizGame 실행, Ctrl+C/EOF 처리
├── game.py        # QuizGame 클래스: 메뉴, 풀기/추가/목록/점수, 저장·불러오기
├── quiz.py        # Quiz 클래스와 기본 퀴즈 8개(default_quizzes)
├── inputs.py      # 공통 입력 처리: 공백 제거, 숫자 변환, 범위 검사, 빈 입력
├── state.json     # 저장 데이터 (퀴즈 목록 + 최고 점수), UTF-8
├── docs/
│   └── captures.md   # 실행 화면 기록
├── .gitignore
└── README.md
```

## 6. 데이터 파일 설명 (`state.json`)

- **경로**: 프로젝트 루트의 `state.json` (`main.py`와 같은 폴더).
- **역할**: 퀴즈 목록과 최고 점수를 저장합니다. 종료할 때, 퀴즈를 추가할 때, 최고 점수가 갱신될 때 저장하고, 시작할 때 불러옵니다.
- **인코딩**: UTF-8 (한글이 그대로 저장됩니다).
- **파일이 없으면** 기본 퀴즈 8개로 시작합니다. **파일이 손상됐거나 형식이 틀리면** 안내 메시지를 보이고 기본 퀴즈로 복구합니다. 저장은 임시 파일에 먼저 쓴 뒤 교체해서, 쓰다가 끊겨도 기존 파일이 깨지지 않습니다.

| 필드 | 형식 | 설명 |
|---|---|---|
| `quizzes` | 목록 | 퀴즈 항목들 |
| `quizzes[].question` | 글자 | 문제 |
| `quizzes[].choices` | 글자 4개의 목록 | 선택지 |
| `quizzes[].answer` | 정수 1~4 | 정답 번호 |
| `best_score` | 정수 0~100 또는 `null` | 최고 점수 (아직 안 풀었으면 `null`) |
| `best_correct` | 정수 또는 `null` | 최고 점수일 때의 정답 수 |
| `best_total` | 정수 또는 `null` | 최고 점수일 때의 전체 문제 수 |

예시:

```json
{
  "quizzes": [
    {
      "question": "Git에서 지금까지 바꾼 내용을 저장소 기록으로 남기는 명령은?",
      "choices": ["git add", "git commit", "git push", "git clone"],
      "answer": 2
    }
  ],
  "best_score": 80,
  "best_correct": 4,
  "best_total": 5
}
```

복제 실습: 다른 폴더에서 clone한 뒤 이 줄을 추가해 push했습니다.
