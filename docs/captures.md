# 실행 화면 캡처 (텍스트)

`python main.py`를 실제로 돌린 출력이다. 입력한 값이 프롬프트 뒤에 보이도록 기록했다. 시험은 저장소가 아닌 **임시 폴더 복사본**에서 해서 `state.json`이 바뀌지 않는다.
